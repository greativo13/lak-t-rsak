# Lakótársak

Közös háztartás-app lakótársaknak: bevásárlólista, otthoni készlet, tartozások és szabadidő (társasjáték-sorsoló + film/sorozat Tinder-match).

Egyfájlos alkalmazás (React + Tailwind + Firebase Firestore). A közzétett fájl az **`index.html`** — ezt szolgálja ki a Netlify.

## Fejlesztés
- A szerkesztendő forrás: `lakotarsak-kozos.html`. Változtatás után másold `index.html`-be (a kettő azonos), és commitold.
- Adat: közös Firebase-háztartás; a kulcsok kliensoldaliak. **A repó legyen PRIVÁT** (TMDB-kulcs + háztartás-azonosító).

## Közzététel
- Netlify a GitHub-repóhoz kötve: minden `main`-re pusholt változás automatikusan élesül. Publish directory: a repó gyökere, build parancs nincs (statikus).
